# Boykisser Shooter

A galaxy shooter game, but it's cats.

**[▶ play it here](https://danielscos.github.io/boykisser-shooter/)**

---

## Controls

| Key | Action |
|-----|--------|
| Arrow Keys | Move |
| Space | Shoot |
| Enter | Start / confirm |

---

## Gameplay

- You have **3 lives**, getting hit by an enemy bullet or a collision costs one life
- Kill enemies quickly to build a combo multiplier

## Tech Stack

- **[KAPLAY](https://kaplay.dev/)** — game framework (Kaboom.js successor)
- **TypeScript**
- **Vite**
- **GitHub Pages** for deployment

---

## Running Locally

```sh
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

### Building & Deploying

```sh
# build only
npm run build

# build + deploy to GitHub Pages
npm run deploy
```
